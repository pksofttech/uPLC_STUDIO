          KEY CAPABILITIES
          
ครบเครื่องเรื่อง PLC สมัยใหม่ในโปรแกรมเดียว

          

            ออกแบบมาเพื่องานการเรียนการสอน งานต้นแบบอัตโนมัติ และงานควบคุมอุตสาหกรรมขนาดเล็กด้วยไมโครคอนโทรลเลอร์
          

        


        

          

            
⚡

            
IEC 61131-3 Ladder & IL Editor

            

              วาดวงจรด้วยเมาส์และคีย์บอร์ดความเร็วสูง รองรับ Contact (NO/NC/P/N), Coil (Normal/Negated/Set/Reset), Branch ขนาน, Multi-line Network Comment และแปลงไป-กลับไฟล์ .il มาตรฐานได้ทันที
            

            

              LD / LDN / LDP
              ST / S / R
              Multi-line Comment
            

          


          

            
🎛️

            
Function Blocks ระดับอุตสาหกรรม

            

              รองรับคำสั่งขั้นสูงครบครันทั้ง Timer (TON, TOF, TP), Counter (CTU, CTD, CTUD), PID Controller, Linear SCALE, LIMIT, MATH, MOVE, BITWISE, Shift Register, ADC และ UART
            

            

              TON / TOF / TP
              CTU / CTD / CTUD
              PID / SCALE / LIMIT
            

          


          

            
🔍

            
Real-Time Simulator & Online Monitor

            

              ทดสอบโปรแกรมได้ทันทีโดยไม่ต้องมีบอร์ดจริง หรือเชื่อมต่อบอร์ด RP2040 ผ่าน USB เพื่อดูเส้นทางการไหลของกระแสไฟ (Live Conduction), ตาราง Watch Table และสั่ง Force I/O แบบสดๆ
            

            

              Live Power Flow
              Watch Table
              Force I/O
            

          


          

            
🧠

            
RP2040 32-bit Micro-VM & RETAIN Flash

            

              คอมไพล์วงจรเป็น Bytecode ขนาดกะทัดรัดพร้อมตรวจเช็ค CRC16 บันทึกลงหน่วยความจำ Flash บนบอร์ด RP2040 และรองรับตัวแปรจำค่าเมื่อไฟดับ (RETAIN: M64..M95, D96..D127)
            

            

              CRC16 Verified
              Flash 0x1FE000
              RETAIN M64..M95
            

          


          

            
🌐

            
Modbus RTU Master (RS-485)

            

              เชื่อมต่อเซนเซอร์วัดอุณหภูมิ มิเตอร์ไฟฟ้า และอินเวอร์เตอร์ (VFD) ผ่านพอร์ต RS-485 ด้วยบล็อกคำสั่ง MB_MASTER (Function 03, 04, 06) พร้อมระบบจัดการ Timeout อัตโนมัติ
            

            

              MB_MASTER
              FC 03 / 04 / 06
              RS-485 DE/RE
            

          


          

            
🚀

            
1-Click USB BOOTSEL Flasher & Auto-Update

            

              มีระบบแฟลชเฟิร์มแวร์ .uf2 ลงบอร์ด Raspberry Pi Pico ในตัวผ่านโหมด USB BOOTSEL และมีระบบตรวจสอบอัปเดตเวอร์ชันโปรแกรมใหม่ผ่านออนไลน์
            

            

              USB BOOTSEL .uf2
              Global Symbol Table
              Auto-Updater
            

          

        

      

    


    
    

      

        

          GETTING STARTED
          
เริ่มต้นใช้งาน LaduinoPLC ใน 4 ขั้นตอน

          

            เมื่อเปิดโปรแกรมขึ้นมา ระบบจะสร้างหน้า New Ladder ที่ว่างเปล่าให้พร้อมเริ่มเขียนวงจรได้ทันที
          

        


        

          

            
01

            
ดาวน์โหลดและเปิดโปรแกรม

            

              ดาวน์โหลดไฟล์สำหรับ Windows หรือ Linux จากหน้า GitHub Releases แตกไฟล์แล้วเปิดโปรแกรม laduino-plc ได้ทันทีโดยไม่ต้องติดตั้งไลบรารีเสริม
            

            

              เปิดโปรแกรมปุ๊บ → เข้าสู่หน้า New Ladder (1 Network ว่าง) พร้อมใช้งานทันที หรือเลือกเมนู Examples เพื่อดูตัวอย่างกว่า 18 โปรเจกต์
            

          


          

            
02

            
วางอุปกรณ์และตั้งค่า IEC Address

            

              คลิกเลือก Contact, Coil หรือ Function Block จากแถบด้านซ้ายแล้ววางลงบนเส้น Rung ดับเบิลคลิกที่ตัวอุปกรณ์เพื่อกำหนด Address (%IX0.0, %QX0.0, T0) และตั้งชื่อ Symbol
            

            

              คีย์ลัด: P = ต่อขนาน (Parallel) | S = ต่ออนุกรม (Series) | Enter = ตั้งค่าอุปกรณ์ | Ctrl+F = ค้นหาและแทนที่
            

          


          

            
03

            
จำลองการทำงาน (Offline Simulator)

            

              สลับโหมดเป็น Simulator แล้วกดปุ่ม ▶ Run (F5) คุณสามารถคลิกที่หน้าสัมผัส Input บนผังวงจรเพื่อสลับสถานะ ON/OFF และดูค่าตัวแปรในแท็บ Watch ด้านขวาได้ทันที
            

            

              คีย์ลัดจำลอง: F5 = Run / Stop | Shift+F5 = Reset | F6 = Single Step (รันทีละ 1 สแกน)
            

          


          

            
04

            
แฟลชเฟิร์มแวร์ & อัปโหลดลงบอร์ด RP2040

            

              กดปุ่ม ⚡ Update to PLC เลือกแท็บ Firmware Flasher เพื่อแฟลชไฟล์ .uf2 ลงบอร์ด Pico ครั้งแรก จากนั้นกด ⬆ Upload to PLC เพื่อส่งโปรแกรม Ladder ลงบอร์ดจริง
            

            

              กด F7 (Online Monitor) เพื่อดูสถานะกระแสไหลจริงจากบอร์ด RP2040 พร้อมระบบเช็ค CRC16 ตรงกับหน้าจอ
            

          

        

      

    


    
    

      

        

          HARDWARE & MEMORY MAP
          
ตารางพินและหน่วยความจำมาตรฐาน (RP2040 Micro-VM)

          

            การแมปพอร์ตมาตรฐานสำหรับบอร์ด Raspberry Pi Pico (RP2040) และ Address ตามมาตรฐาน IEC 61131-3
          

        


        

          

            
              

                หมวดหมู่ (Region)
                IEC 61131-3 Address
                PLC Alias
                พินฮาร์ดแวร์ RP2040

                Digital Inputs
                %IX0.0 – %IX0.7
                X0 – X7
                GP2 – GP7, GP15, GP16
                อินพุตดิจิทัล 8 ช่อง (Active-High / Pull-down) พร้อมระบบ Force I/O
              

              

                Digital Outputs
                %QX0.0 – %QX0.7
                Y0 – Y7
                GP25 (LED), GP8 – GP14

                %MX8.0 – %MX11.7

                RP2040 Flash

                Data Registers
                %MW0 – %MW95
                D0 – D95

                Retentive Registers (RETAIN)
                %MW96 – %MW127
                D96 – D127

                %IW0 – %IW3
                AI0 – AI3

                Modbus RTU (RS-485)
                MB_MASTER

                Special System (%SM / %SD)

                M8000+ / D8000+

            01 / DIGITAL INPUT WIRING
            
การต่อสวิตช์ & เซนเซอร์อินพุต (%IX0.0..%IX0.7)

            

              พิน GP0..GP7 ตั้งค่าเป็น Internal Pull-Down (Active-High 3.3V) สำหรับงานอุตสาหกรรม 24VDC แนะนำให้ต่อผ่านโมดูล Optocoupler (เช่น PC817)
            

            

              
            

          


          

            02 / DIGITAL OUTPUT WIRING
            
การต่อรีเลย์ & โซลินอยด์เอาต์พุต (%QX0.0..%QX0.7)

            

              พิน GP25 (LED Y0) และ GP8..GP14 (Y1..Y7) จ่ายลอจิก 3.3V แนะนำให้ต่อเข้าโมดูล Relay Opto-Isolated หรือไอซี ULN2803 เพื่อขับโหลดกำลังสูง
            

            

              
            

          


          

            03 / RS-485 MODBUS RTU
            
การต่อโมดูล RS-485 (MB_MASTER)

            

              เชื่อมต่อโมดูล MAX485 / SP3485 (3.3V) เข้ากับพิน UART พร้อมพินควบคุมทิศทาง DE/RE อัตโนมัติ สำหรับอ่านค่าเซนเซอร์และสั่งงานอินเวอร์เตอร์
